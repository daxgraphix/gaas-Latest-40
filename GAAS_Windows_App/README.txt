# GAAS Windows App
# Math Learning Adventure

## Description
GAAS (Gaming Adventure for Arithmetic Skills) is a comprehensive math learning app designed for primary school students. It features adaptive difficulty, multiple game modes, and engaging gameplay to make learning mathematics fun and effective.

## Features
- ✅ 45 questions per campaign level (35+ correct to unlock next)
- ✅ Progressive difficulty: Single → Double → Triple digits
- ✅ Multiple game modes: Campaign, Arcade, Practice, Crosswords, Logic Riddles
- ✅ Adaptive difficulty based on performance
- ✅ Cross-platform support (Android & Windows)
- ✅ No remainders in all division problems
- ✅ Comprehensive question banks (1000+ questions)
- ✅ Progress tracking and achievements
- ✅ Responsive design for all screen sizes

## System Requirements
- Windows 10 or higher
- Minimum 4GB RAM
- 500MB free disk space
- DirectX compatible graphics

## Installation
1. Extract all files to a folder
2. Run `GAAS_Windows_App.exe`
3. Enjoy learning math!

## Game Modes
- **Campaign**: 50 progressive levels with story-driven gameplay
- **Arcade**: Time-based challenges with increasing difficulty
- **Practice**: Unlimited practice with customizable settings
- **Crosswords**: Fill in missing numbers in equations
- **Logic Riddles**: Math puzzles and brain teasers

## Controls
- **Mouse**: Click to select answers and navigate
- **Keyboard**: Use arrow keys for navigation, Enter to confirm
- **Touch**: Tap for mobile/tablet experience
